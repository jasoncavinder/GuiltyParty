# Licensing and Intellectual Property Policy

## Purpose

This document describes the intended intellectual property model for Guilty
Party.

It is an internal project reference and does not replace the official license
files.

---

# Project Ownership

Guilty Party is intended to become a proprietary commercial platform.

The project owner retains ownership of:

- source code
- architecture
- technical designs
- protocols
- infrastructure
- product concepts
- branding
- platform technology

---

# Public Repository Philosophy

The repository is public to support:

- professional portfolio visibility
- technical discussion
- transparency
- demonstration of engineering practices

Public visibility does not imply open-source licensing.

---

# Platform IP

Platform intellectual property includes:

## Software

Examples:

- web applications
- mobile applications
- television applications
- desktop applications
- backend services
- shared libraries

## Technical Systems

Examples:

- scenario engine
- session management
- device pairing
- media routing
- AI Stage Manager
- creator tooling

## Documentation

Examples:

- architecture documents
- design specifications
- development processes

---

# Content IP

Content is distinct from platform technology.

Examples:

- murder mysteries
- character profiles
- scripts
- artwork
- music
- sound effects
- interactive scenarios

Future content licensing must support:

- independent creators
- professional studios
- partnerships
- marketplace distribution

---

# Future Creator Marketplace

The creator ecosystem should support:

- creator ownership
- attribution
- licensing flexibility
- revenue sharing
- commercial opportunities

Creator agreements should define:

- ownership
- platform rights
- distribution rights
- modification rights
- revenue terms

---

# Contributions

Until a formal contributor agreement exists:

- Do not accept large external code contributions.
- Do not imply contributor ownership transfer.
- Do not merge third-party intellectual property without clear rights.

Small suggestions and discussions may be incorporated at the discretion of
the project owner.

---

# Trademarks

The following may become protected trademarks:

- Guilty Party
- Guilty Party branding
- Logos
- Product names
- Scenario names

Trademark protection should be evaluated separately from software licensing.

---

# Future Legal Work

Before commercial launch, professional review should address:

- Terms of service
- Privacy policy
- Creator agreements
- Host agreements
- Content licensing
- User safety policies
- Liability limitations
- Payment terms
- International requirements

---

# Guiding Principle

The goal is:

> Public enough to demonstrate engineering quality and build trust, while
> protected enough to support a sustainable commercial product.
